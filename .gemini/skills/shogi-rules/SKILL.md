# 5×5 将棋ルール

---

## 1. 初期配置

```
  1   2   3   4   5
┌───┬───┬───┬───┬───┐
│ 飛 │ 角 │ 銀 │ 金 │ 王 │  ← 相手陣 (後手/gote)
├───┼───┼───┼───┼───┤
│   │   │   │   │ 歩 │
├───┼───┼───┼───┼───┤
│   │   │   │   │   │  ← 中央
├───┼───┼───┼───┼───┤
│ 歩 │   │   │   │   │
├───┼───┼───┼───┼───┤
│ 王 │ 金 │ 銀 │ 角 │ 飛 │  ← 自陣 (先手/sente)
└───┴───┴───┴───┴───┘
```

- 自陣1段目: 左から「王・金・銀・角・飛」
- 自陣2段目: 王の前に「歩」を1枚
- 相手陣: 点対称に配置
- 持ち駒: 初期状態では無し

## 2. 駒の種類と成り

| 駒 | 英名 | 成駒 | 動き |
|----|------|------|------|
| 王 | King (OU) | — | 全方向1マス |
| 金 | Gold (KIN) | — | 前・横・斜め前・後ろ 1マス |
| 銀 | Silver (GIN) | 成銀 | 前・斜め 1マス |
| 角 | Bishop (KAKU) | 馬 | 斜め方向（何マスでも） |
| 飛 | Rook (HI) | 竜 | 縦横（何マスでも） |
| 歩 | Pawn (FU) | と金 | 前1マス |

### 成りの条件

- 敵陣の1段目に入ったとき、またはそこから出るときに**選択可能**
- **強制成り**: 歩が一番奥の段に進んだ場合は必ず「と金」に成る

## 3. 持ち駒と「打つ」

- 相手の駒を取ると自分の持ち駒になる
- 成駒（成銀・と金）を取った場合は**元の駒（銀・歩）に戻る**
- 自手番で盤上の空いているマスのどこにでも「打つ」ことができる

## 4. 禁手・反則

| 禁手 | 説明 |
|------|------|
| 二歩 | 同じ縦列に自分の「歩」を2枚置く |
| 王手放置 / 自殺手 | 王が取られる状態を放置、または自ら利きに移動 |
| 行き所のない駒 | 一番奥の段に「歩」を打つ |
| 打ち歩詰め | 持ち駒の「歩」を打って即座に詰ませる |

## 5. 勝敗条件

- 相手の王将を詰ます（チェックメイト）
- 相手の投了
- 相手の切断

> **注意**: 時間制限なし。持ち時間や1手あたりの制限時間は存在しない。
